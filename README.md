An original 3D open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty. Rex Marlowe is back in Solmar Bay with no money, no car and one friend left: fixer Lena Voss. Five jobs stand between him and the big score.

Explore a sun-soaked grid city on foot and by car, steal cars, dodge traffic and pedestrians, earn a wanted level and lose the police chasing you, run five story missions, and save your progress. Everything is static files — no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or open `game/index.html` from any static file server.

## Controls

- **W A S D** move / drive · **Shift** run · **Space** jump
- **Mouse drag** look around · **Click** shoot · **R** reload
- **E** steal car / get out / hold at the vault · **Esc** pause · **M** mute

## What is in the game

- A 7×7-block city with a beach and ocean, palms, plazas and a fountain
- Traffic that cruises the road grid and pedestrians who stroll — and flee
- Cars to steal and drive, with arcade handling and damage smoke
- A 5-star wanted system: foot cops who chase and bust you, police cars that ram you
- Five story missions: steal wheels, run a package, lose the heat, rob the Bay Bank, take down the Vipers' stash
- Combat with a pistol, a HUD with health, cash, wanted stars and a live minimap
- Synthesised WebAudio sound: engine hum, sirens, gunshots and a sunset groove — no audio files
- Saving to localStorage, start / pause / busted / wasted screens
